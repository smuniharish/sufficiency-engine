# Security

Do not disclose exploitable vulnerabilities or sensitive data in a public
issue. Use the repository's private vulnerability-reporting feature if it is
enabled, and include reproduction steps without real credentials or user data.

Sufficiency Engine does not authenticate callers, execute tasks, or guarantee
that a model discovers every requirement. Applications must enforce access
control, protect task and answer data, and assess the suitability of model
providers and persistence implementations. See the
[security guide](docs/security.md) for trust boundaries.
