# How-to guides

[Quickstart](../../getting-started/quickstart.md).

| Guide | Use it to |
| --- | --- |
| [Recover an interrupted assessment](recover-interrupted.md) | Resume after a failed interaction callback, a malformed response, or an AGXAI outage |
| [Use durable storage](durable-storage.md) | Keep sessions and provenance across restarts, and check your adapters |
| [Evaluate a discovery model](evaluate-discovery.md) | Measure false-ready and false-not-ready outcomes with your own model and labeled cases |
| [Detect semantic duplicates](semantic-duplicates.md) | Add an embedding model that reports near-duplicate questions |
| [Validate a deployment](validate-deployment.md) | Work through the acceptance checklist before going to production |
