# Getting started

Three steps, from installation to a first audited readiness decision. None of
them needs a model provider or an external service.

<div class="grid cards" markdown>

-   :material-download:{ .lg .middle } __[Installation](installation.md)__

    ---

    Install the core from source, and add the LangGraph or OpenTelemetry extra
    when you need it.

-   :material-rocket-launch:{ .lg .middle } __[Quickstart](quickstart.md)__

    ---

    Connect a model callback, answer one clarification question, and read the
    audited result.

-   :material-tune:{ .lg .middle } __[Configuration](configuration.md)__

    ---

    Set iteration and retry budgets, assumption policy, input limits, and the
    components each engine uses.

</div>

After the quickstart, the [User guide](../guide/index.md) explains how
requirements are evaluated and walks through common tasks.
